# ISABELLINE

A quiet candle brand website that turns into a Halloween night store.

Portfolio project. ISABELLINE is a fictional brand and this is not a real store. No payment is processed.

## Concept

1. ISABELLINE: ivory and black, a calm brand page.
2. ENTER THE NIGHT: the page goes dark and someone knocks on the door.
3. The Night: pick up the flame and light the limited candles.
4. Shop: product detail, cart, checkout and order complete.

## Structure

```
assets/
  layout/    images used in the Figma layout
  images/    web images (WebP)
    basic/     ISABELLINE main
    night/     Halloween hero, door, candle
    products/  Halloween products
  video/     intro video, candle loop
  favicon/
data/        products and KR/EN copy (coming)
```
